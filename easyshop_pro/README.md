# EasyShop Pro

Enhanced beginner-friendly online shopping app using Python Flask + SQLite.

## Features
- Real product images
- Featured products and modern responsive UI
- Search, category filter and price/rating sorting
- Product detail pages
- Wishlist
- Shopping cart and quantity controls
- Checkout with demo payment choices
- Orders and stock reduction
- Reviews and ratings
- User profile
- Admin dashboard
- Add/delete products and update order status

## Run
pip install -r requirements.txt
python app.py
Open http://127.0.0.1:5000/
